DAGORA – Digitale Verwaltungsplattform (Prototyp)

Hinweis: Dieses Repository enthält den Code für den funktionalen Prototyp „DAGORA“, 
der im Rahmen meiner Bachelorarbeit entwickelt wurde. Ziel war es, einen einfachen, lokal lauffähigen Prototyp zu bauen, 
der typische Verwaltungsprozesse (z. B. Wohnsitzanmeldung oder Personalausweis-Verlängerung) teilautomatisiert abbildet, mit Fokus auf Benutzerfreundlichkeit, Transparenz und Zukunftsvision.

Inhalte:

- Bürgerportal mit Antragstellung & Statusverfolgung
- Verwaltungsportal zur Antragsbearbeitung
- LocalStorage & SessionStorage zur Datenspeicherung
- Formularvalidierung & Statuslogik
- Prototyp vollständig clientseitig (HTML, CSS, JS)
